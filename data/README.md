# Data

## Source and provenance

A real, order-level Swiggy dataset is not publicly available (Swiggy does not
release raw order/rider data). Public proxies (e.g. NYC TLC trip records,
Kaggle "Zomato"/"food delivery" aggregate datasets) either lack the joint
structure needed here (timestamped order-level demand **and** ETA features
**and** zone/rider context) or are too small/aggregated to support the lag,
rolling-window and multi-horizon forecasting work required by this project.

Given that constraint, this project uses a **clearly-labelled synthetic
dataset**, generated by [`src/data/generate_dataset.py`](../src/data/generate_dataset.py),
built from realistic assumptions about food-delivery demand and calibrated
against publicly known patterns (lunch/dinner peaks, weekend uplift, monsoon/
traffic effects on ETA, distance-driven delivery time, etc.). **No field in
this dataset is real Swiggy data or derived from any Swiggy system.**

The generator is a full simulation with:
- A city of 12 zones with different baseline demand levels and speeds.
- 150 restaurants distributed across zones and 6 cuisine types, each with its
  own popularity, base prep-time, and volatility.
- 90 days of order-level events at minute granularity, respecting daily/weekly
  seasonality, weather, and traffic regimes that evolve over the day.
- Order-level features (basket size, item count, distance, rider availability)
  and derived ETA built from a structural (non-linear, noisy) formula, so
  that ML models have real signal to recover but also irreducible noise.

Everything downstream (`data/processed/`) is derived from this synthetic raw
data via `src/features/`.

## Regenerating the data

Raw and processed data files are **not** committed to git (see `.gitignore`)
because they are fully reproducible from a fixed random seed:

```bash
python -m src.data.generate_dataset --out data/raw --seed 42
python -m src.features.build_features --raw data/raw --out data/processed
```

## Files (generated)

- `data/raw/orders.parquet` — order-level fact table (~1.6M rows over 90 days)
- `data/raw/restaurants.parquet` — restaurant dimension table
- `data/raw/zones.parquet` — zone dimension table
- `data/raw/weather_traffic.parquet` — hourly weather/traffic by zone
- `data/processed/demand_timeseries.parquet` — zone x restaurant x 30-min bucket demand panel with engineered features
- `data/processed/eta_features.parquet` — order-level ETA modeling table with engineered features
